Database setup

The site needs three tables — admins, enquiries and settings — plus the is_admin() helper and their row level security policies. Press Check tables to see what is missing.

Option A — run it from your terminal (recommended)

One command creates everything. It needs the database password or the service_role key, which stay on your machine and are never committed. 

npm run supabase:setup
